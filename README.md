🚗 Meu Combustível — Aplicativo .NET MAUI
O Meu Combustível é um aplicativo desenvolvido em .NET MAUI para ajudar motoristas a controlar gastos com combustível, calcular consumo, registrar abastecimentos e tomar decisões mais inteligentes entre etanol e gasolina.
O app é leve, rápido e multiplataforma — funcionando em Android, iOS, Windows e macOS.

✨ Funcionalidades
  📊 Cálculo automático de consumo (km/L)
  ⛽ Registro de abastecimentos com preço, quantidade e data
  🔄 Comparação etanol vs gasolina com recomendação baseada no custo-benefício
  🧮 Simulador de economia
  🗂️ Histórico de abastecimentos
  🎨 Interface moderna construída com .NET MAUI XAML
